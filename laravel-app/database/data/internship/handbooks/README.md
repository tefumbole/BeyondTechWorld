# Beyond Internship Student Handbooks

Same Day-1 handbook pattern for **all 11 programs × 180 days**.

## Generator

```bash
python3 generate_program_day_handbook.py --program ARTIFICIAL_INTELLIGENCE --days 2-180
python3 generate_program_day_handbook.py --all-programs --days 1-180
```

AI Day 001 is never overwritten (canonical ChatGPT/Day-1 reference).

## Structure (every day)

Title page, how-to-use, schedule, outcomes, key concepts, authorization, install/verify, folders, environment, step-by-step lab, responsible checkpoint, evaluation, verification, troubleshooting, evidence, report guide, checklists, self-check, supervisor pitch, rubric, official references.
